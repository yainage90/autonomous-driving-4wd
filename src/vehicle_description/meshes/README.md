# 섀시 메시

`four-wheel-drvie-main-body.stl`은 면 방향이 수정된 원본 ASCII STL이다.
URDF는 여기서 분리한 `chassis_body.stl`과 네 개의 `*_wheel.stl`을 사용한다.
원본 삼각형 225,636개를 빠짐없이 분배하고 binary STL로 저장한다.
파생 파일 합계는 약 11.28 MB로, 삼각형 수를 줄이는 단순화는 하지 않았다.

## 좌표와 치수

STL에는 단위/차량 전방 정보가 없으므로 다음을 모델링 가정으로 사용한다.

- 좌표 단위는 m: 상판 228 × 148 × 2 mm, 하판 약 228 × 110 × 2 mm와 일치한다.
- 원본의 −Z 방향을 차량 전방으로 선택한다.
- 회전 변환은 ROS `(x, y, z) = STL (-z, -x, y)`이다.
- 차체 원점은 원본 `(0, 0.03453, -0.011)` m, 즉 네 바퀴 축의 중심이다.
- 바퀴 메시는 각 타이어 외접 경계의 중심으로 옮겨 Y축 주위로 회전한다.
  허브, 축 끝 나사, 허브 고정 나사도 해당 바퀴에 포함한다.
- 바퀴 조인트는 앞뒤 ±49.7 mm, 좌우 ±60.15 mm, 높이 0으로 정렬한다.
  원본의 미세한 비대칭(한 바퀴 높이 약 0.013 mm 차이)은 정규화한다.

| 항목 | 값 |
|---|---:|
| 바퀴 반지름 | 33.5 mm |
| 타이어 폭 | 27 mm |
| 축간 거리 | 99.4 mm |
| 좌우 타이어 중심 간격 | 120.3 mm |
| 판 중심 X (바퀴 축 중심 기준) | −6 mm |
| 하판 중심 Z (바퀴 축 높이 기준) | 25.65 mm |
| 상판 중심 Z (바퀴 축 높이 기준) | 67.65 mm |
| 판 사이 빈 공간 | 40 mm |

외형은 메시를 사용하고, 충돌 형상은 판/모터의 박스와 지지대/바퀴의 원통으로
근사한다. 판의 구멍과 작은 체결 부품은 충돌 형상에 표현하지 않는다.
카메라 매립부 역시 상판 충돌 박스에 개구부가 없는 근사 모델이다.

새 원본의 상·하판 표면은 바깥쪽을 향하고, 일반적인 두 면 사이의 모서리에는
면 방향 불일치가 없다. 지지대 6개에 남은 156개의 네 면 공유 모서리는 원본대로
보존한다. 이 메시를 물리 충돌이나 정밀 체적 계산용 폐곡면으로 가정하지 않는다.

센서와 보드의 XY 배치는 기존 추정값을 유지하고 장착 높이를 상판에 연동한다.
배터리는 하판 위에 놓는다. 배터리 높이 38 mm 기준 상판 아래 여유는 2 mm이다.
차체 질량과 관성은 기존 추정값이며, 차체 무게중심은 판 사이 중심으로 근사한다.
바퀴 질량도 기존 40 g 추정값이고 관성만 새 치수의 균일 원통으로 재계산한다.
실제 전방, 센서 장착 위치와 질량 분포는 실물 확인이 필요하다.

## 재생성

원본 STL은 저장소에 포함하지 않는다. 재생성하려면 면 방향이 수정된 원본을
`src/vehicle_description/meshes/four-wheel-drvie-main-body.stl`에 준비하거나
`--source /path/to/source.stl`로 경로를 지정한다.
워크스페이스 루트에서 Python 3.12 표준 라이브러리만으로 실행할 수 있다.

```bash
source .venv/bin/activate
python src/vehicle_description/scripts/build_chassis_meshes.py
```

스크립트의 부품 판별은 이 원본 STL의 67 mm 바퀴와 허브 위치에 맞춰져 있다.
원본이 바뀌면 판별 조건과 URDF 치수를 함께 검토해야 한다.
패키지 설치에는 파생 binary STL 다섯 개만 포함한다.
